# Asset credits

The SP Rose oil column is by **Crusher / Mecrusher**, provided separately in [Crusher's Trucks And Assets](https://www.nexusmods.com/railroader/mods/1766) (`CLW_Assets`). BMR Bunker C Refuellers requires that pack; it does not redistribute the Unity bundle or its asset definitions.

- Asset/model identifier: `SPRoseOilColumn`.
- Scenery identifier: `scenery://SPRoseOilColumn`.
- Prefab filename: `sproseoilcolumn.prefab`.
- Asset catalog: `SpRoseOilColumn`.

BMR supplies the placement, industry, delivery-span and Toolshed service bindings. The external pack supplies the column model, arm animation and authored Bunker C load point with its visible oil stream.

All current BMR loader placements use Crusher's column, including Foxy's Alarka adaptation. Baseplates are supplied separately by **C_L_B's ASSETS01**.

Earlier versions used the tank-loader model from **ALW Scenery Assets for FUSE**. That asset pack is no longer required by BMR Bunker C Refuellers.
